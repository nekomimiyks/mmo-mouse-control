# MMO Mouse Control privacy policy

MMO Mouse Control works locally on your PC. The app does not require an account or send mouse settings, input data, or diagnostics to a server.

The app reads settings and button reports from supported mice to show button activity and configure the device. It also reads current Windows input while the app is focused for input display and shortcut capture. Mouse settings, shortcuts, backups, and G600 diagnostic logs can be stored locally. The app can change Windows pointer and scrolling settings when you choose to do so.

The GitHub edition connects to GitHub when you check for updates. Automatic checks are off until you enable them. The update check does not upload mouse settings, input data, backups, or diagnostic logs. Microsoft Store manages updates for the Store edition.

For questions, use the [project issue tracker](https://github.com/nekomimiyks/mmo-mouse-control/issues).
